A full-stack web application designed for medical and dental institutions to manage academic, clinical, and administrative workflows in one centralized platform.

## 🛠️ Tech Stack
Python · Django · MySQL (Railway) · JavaScript · HTML · CSS

## 👥 Stakeholders
Admin · Medical & Dental Students · Doctors · Intern Doctors · Faculty · Library Staff · Ward Authority

## ✨ Key Features
- Role-based access control for 7 stakeholder types
- Internship eligibility verification & ward posting management
- Clinical case log tracking & academic examination system
- Library management & fee/payment processing
- Analytics dashboard with downloadable reports

## 🚀 How to Run
```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```
